# 色序：产品与微信接入方案

## 目标与首版范围

用户不需要理解专业调色参数，也能知道照片是什么色调，试出喜欢的风格，得到可分享的成片。

本次交付是独立全栈 Web MVP，桌面与手机浏览器共用后端；微信小程序作为下一阶段。没有将“手机网页适配”称作已完成微信小程序。

当前决策：先做完全免费版本。手动调整、系统推荐、全部风格、收藏与原尺寸导出均免费；界面不显示 Pro、VIP、会员分级或广告解锁。系统推荐未来是否收费、如何收费尚未确定，不预设收费流程。

## 核心流程

1. 首屏自动载入示例照片，直接展示真实分析结果和风格，降低第一次操作门槛。
2. 点击上传或拖入图片。手机使用系统照片选择器。支持状态：处理、完成、格式错误、超限、无可见像素、网络失败。
3. 展示最多六种采样色、面积比例、HEX、描述性中文色名、最近参考色卡。点开颜色查看 RGB/HSL/CMYK、参考编号与色差。
4. 自动分析亮度、饱和度、冷暖关系，根据这些特征推荐风格。推荐卡片紧接分析文案，用户可一键应用，也可在六种方案中切换。选择风格会恢复 75% 风格强度并清空手动调整，界面明确说明。
5. 「原图对比」短按切换分屏；鼠标或手指持续按住 220 毫秒后显示完整原图，松开恢复完整最新效果。拖离、指针取消、失焦、切后台、组件卸载均清理按住状态。原图画布提前准备，长按不重新请求或等待计算。
6. 手动精调包含光感（曝光、明度、对比度、高光、阴影、褪色）、色彩（相对色温、色调、饱和度、自然饱和度、分离色调）、细节（锐化、颗粒、暗角），以及八色 HSL 通道。所有参数实际作用于画面；HSL 色相 -100～100 映射为约 -30°～30°，色温为相对调整，并非 Kelvin。手动参数在风格之后叠加，不受风格强度归零影响。「还原」同时将风格强度和全部手动参数归零。
7. 收藏方案保存风格、强度、全部手动参数与配色，仅保存在当前浏览器；不额外保存用户原图。旧版收藏缺失的手动参数自动补零。
8. 点击「免费导出图片」后直接选择 JPG 或 PNG，无需观看广告或等待。
9. 导出包含所选风格与手动参数，保留原始尺寸，原图保持不变。新上传的照片同样可直接免费导出。预览与导出复用同一处理函数；预览压缩、缩放及细节半径取整意味着不同分辨率显示不保证逐像素相同。

## 布局

桌面：左侧固定导航 → 顶部工作区信息 → 上传标题区 → 左大图/右分析 → 风格卡片 → 当前方案解释 → 导出区。调色建议页面右侧为突出显示的推荐卡片与深色精调面板，左侧预览随页面滚动吸附，调整较下方参数时仍能看到成片。

手机：轻量顶部导航 → 上传与预览 → 对比/强度 → 色彩与建议标签页 → 横向滑动的风格卡片 → 收藏 → 底部吸附导出区。核心操作均为触摸控件，关闭弹窗后回到原操作位置。

色卡探索独立页面支持搜索、材质和色系筛选；收藏独立页面支持复用和移除。首版不引入账户、社区、付费会员或大模型调用。

## 色彩专业性

- 原始数据全部入自有 SQLite，并保存可复核的 JSON 数据快照与来源。
- 原始色卡的 Lab 白点不明，统一从 sRGB 转 D65 Lab 后计算 CIEDE2000，避免混用白点。
- “照片采样色”不等于“参考色卡”。两个 HEX、名称与色差在详情中分别呈现。
- 中文名来自描述规则，如暖砂、奶杏、焦糖棕；不冒充标准色号。
- CMYK 不具备独立于印刷条件的唯一映射。原始值保留，换算值标记近似，不能充当印刷配方。
- 当前聚类为缩小图采样统计，适合照片氛围分析；不作为仪器级测色。
- 色调的冷暖由图像 Lab 色度统计近似判断；不是相机白平衡或色温 Kelvin 的准确反演。
- 风格是全局像素处理，不包含人像分割、肤色保护、局部蒙版或 RAW 显影。

## 微信小程序下一阶段

1. 准备微信小程序主体与 AppID；确认数据商用许可。
2. 用 Taro/React 实现小程序页面，复用 `shared/` 算法、风格定义、色库及后端 API；Canvas 和文件选择/保存用微信适配层替换。
3. 接入 `wx.login`，后端换取 OpenID 并创建用户会话。不要将 Web 的 Cookie 会话直接假定为小程序登录。
4. 配置 HTTPS API、request/uploadFile/downloadFile 合法域名与隐私声明。接入 `wx.chooseMedia`、`wx.uploadFile`、`wx.downloadFile`、`wx.saveImageToPhotosAlbum`；用户拒绝相册权限时提供设置入口和可重试操作。
5. 保持 Web 的手动调色、推荐、收藏与原尺寸导出免费；移动端复用同样的用户流程。
6. 真机验收 iOS/Android：选图、长图、大图、切后台、网络中断、相册授权拒绝与再次保存。

## 运营与成本

分析、匹配、调色不需要调用付费大模型。主要成本为服务计算、图片带宽与临时存储。先验证“上传 → 预览 → 调整 → 导出”流程的完成率与使用体验。

实现位置、机器实测、按量估算与固定服务器费用摊销见 [处理架构与成本](architecture-costs.md)。当前全部免费，服务成本由产品方承担。

未来商业模式另行讨论；当前不增加收费入口、会员权益或广告任务。

Web/Mobile Web、色库导入、图片分析、预览、收藏与免费导出已经实现。正式域名与部署、微信小程序包、微信登录和相册保存仍属于未实施的上线阶段，不能对外宣传为已上线能力。
