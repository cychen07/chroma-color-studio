# 色序 CHROMA

上传照片 → 识别真实主色、色系与冷暖关系 → 六种风格与手动精调 → 免费原尺寸导出。

这是可以本地运行的完全免费全栈 MVP，包含响应式桌面 Web 与手机 Web 界面。手动调整、系统推荐、收藏和导出全部免费，无会员分级或广告等待。当前没有发布微信小程序。

## 启动

需要 Node.js 22.13+（使用内置 SQLite；开发环境验证为 Node 24.7）。

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。TRAE 的运行按钮也已配置。前后端共用一个端口。手机与电脑连接同一 Wi-Fi 后，用电脑的局域网 IP 加 `:3000` 访问；浏览器剪贴板功能在非 HTTPS 环境可能不可用。

```bash
npm run build
npm start
```

`npm start` 为生产模式，需要先构建；使用 HTTPS 反向代理。开发和生产模式均直接开放免费导出。仅在本地验证 HTTP 生产构建时可以设置 `SECURE_COOKIES=false`，不要用于公网部署。

## 已实现

- 真实图片处理：JPG / PNG / WebP，最大 20 MB、2400 万像素。自动应用 EXIF 方向、转为 sRGB、去除原始元数据。
- 主色聚类：Lab 空间 K-means，最多 6 种主色，百分比相加为 100；透明区域不纳入采样。
- 感知匹配：CIEDE2000 色差，统一从 sRGB 计算 D65 Lab，显示匹配色号与 ΔE₀₀。
- 六种风格：自然本色、日落胶片、奶油柔光、青橙电影、森系呼吸、黑白留白。共享像素算法用于 Canvas 预览与 Sharp 原尺寸导出。
- 交互：上传/拖入图片、原图分割对比、风格强度、还原、放大、颜色详情、收藏/移除/复用方案。
- 色库：SQLite 持久化，搜索名称/HEX、按 C/U 与色系筛选、分页。
- 导出：直接免费导出，包含全部手动调整。PNG 保留透明度，JPG 高画质、白色透明背景；不加水印，不改变原图。
- 图片会话隔离，上传/导出限流，同源校验，24 小时有效期与周期清理。

## 色卡数据

源应用：https://ucngz4c73vdl.feishu.link/app/app_17fnstqv4s4

从公开页面所加载的应用数据中解析了 **4,990 条**真实记录：

| 集合 | 实际记录 |
| --- | ---: |
| Solid Coated / C | 2,614 |
| Solid Uncoated / U | 2,376 |

U 页标题显示 2,390，但源码数据和实际渲染集合均只有 2,376。没有为了凑齐标题而补造数据。色号、HEX、RGB、CMYK、HSV、Lab、分类字段全部保存在 `data/colors.json`；附有来源、获取时间、源文件 SHA-256 与核查说明。

部分原始 CMYK 为全零，源 Lab 的白点也未说明。保留原始字段，但匹配用统一计算的 D65 Lab，界面区分“原始数值”和“近似换算”。中文名称是采样色描述，不是声称官方认证的色名。PANTONE 屏幕近似色不等于印刷实物；商业发布前确认来源数据的再分发与商用许可。

导入脚本只解析数据字面量，不执行第三方 JavaScript：

```bash
npm run import:colors
# 或使用下载好的公开 bundle
node scripts/import-colors.mjs /path/to/bundle.js
```

源站更换构建版本时，需要先观察新的公开资源 URL，再更新脚本；脚本不会尝试读取受限接口。

## 验证

保持服务运行后执行：

```bash
npm run verify
npm run verify:adjustments
```

检查公开 CIEDE2000 基准对、真实单色图分析、透明图片、损坏文件、会话隔离、直接免费导出、原尺寸 PNG/JPEG、实际黑白输出和手动参数逐像素一致性。两个脚本均可验证开发或生产模式，不再等待计时。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `src/` | React 桌面/手机响应式界面 |
| `shared/` | 色彩空间、色差、风格与共享像素算法 |
| `server/` | Express、SQLite、Sharp、图片分析与免费导出接口 |
| `data/colors.json` | 已导入的原始色卡与出处 |
| `data/chroma.sqlite` | 启动生成的数据库（不入版本控制） |
| `data/uploads/` | 临时图片（不入版本控制） |
| `public/sample.jpg` | 生成的示例摄影，用于直接体验 |
| `docs/product.md` | 产品决策、用户流程与微信落地边界 |

`PORT` 可改端口；`DATA_DIR` 可指定持久化数据目录。当前为单实例 MVP，公网大流量部署需增加图片队列、对象存储、整体资源配额、审计与监控。
